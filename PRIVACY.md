# OpenDex Privacy Policy

Effective date: 2026-09-18

Policy URL: https://github.com/Grumbo-pc/OpenDex/blob/main/PRIVACY.md

Support: https://github.com/Grumbo-pc/OpenDex/issues

OpenDex is a local desktop application. It does not create accounts, collect analytics, use advertising identifiers, transmit device data to an OpenDex service, or sell/share personal data.

OpenDex stores only the user-selected connection preferences (tool paths, video size, frame rate, bitrate, and session switches) in the app's local webview storage. The app communicates with a USB- or network-authorized Android device through bundled or user-configured ADB and scrcpy tools. Video and control traffic remains between this computer and the connected device.

OpenDex does not access the camera, microphone, location, contacts, calendar, or Windows account information. Files are transferred only when the user explicitly drags a file into the scrcpy session.

For privacy questions, open an issue at the support URL above. This policy will be updated if OpenDex's data practices change.
